# Template — Instrucciones de ensamble

## Formato

```
# Ensamble: <Nombre del mueble>

## Herramientas necesarias
- Taladro, broca 3mm, broca 5mm
- Atornillador, destornillador Phillips
- Escuadra, nivel, cinta métrica
- Cola de carpintero (PVA)
- Lija grano 120/220
- EPP: lentes, guantes, protección auditiva

## Materiales
- Lista de corte (ver cutlist.csv)
- BOM de herrajes (ver bom.csv)

## Pasos

### 1. Preparación
1.1 Verificar todas las piezas según lista de corte.
1.2 Lijar bordes y aplicar canto donde corresponda.
1.3 Marcar puntos de perforación según plano.

### 2. Ensamble de estructura
2.1 Unir laterales con tapa y base usando tornillos confirmat.
2.2 Verificar escuadra con escuadra de carpintero.
2.3 Instalar refuerzos (travesaños) si aplica.

### 3. Instalación de herrajes
3.1 Montar bisagras a 100mm del borde superior e inferior.
3.2 Instalar correderas con 13mm de holgura lateral.
3.3 Montar neumáticos según ficha del fabricante.

### 4. Acabado
4.1 Lijar toda la superficie.
4.2 Aplicar sellador/barniz/pintura.
4.3 Instalar puertas y cajones.
4.4 Verificar funcionamiento y ajustar.

### 5. Fijación final
5.1 Fijar a pared con escuadra o cincha (muebles altos).
5.2 Verificar estabilidad y nivel.

## Notas de seguridad
- Usar EPP en todo momento.
- No exceder cargas calculadas.
- Fijar a pared todo mueble alto (> 600 mm).
```

## Reglas

- Pasos numerados y agrupados por fase.
- Incluir herramientas y EPP.
- Referenciar lista de corte y BOM.
- Incluir verificación de escuadra y nivel en cada fase.
- Agregar notas de seguridad al final.
- Para metal: incluir pasos de soldadura (preparación, cordón, inspección).
- Para soldadura: especificar electrodo, corriente, posición.
