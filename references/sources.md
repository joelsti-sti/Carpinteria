## Libros recomendados para profundizar

1. **USDA Wood Handbook** — propiedades y diseño de madera.
2. **AISC Steel Construction Manual** — acero estructural.
3. **AWS D1.1** — soldadura.
4. **Shigley — Mechanical Engineering Design** — pernos y uniones.
5. **Timoshenko — Resistencia de Materiales** — fórmulas de vigas.
6. **Carpintería moderna (varios autores)** — técnicas de ensamble.

## Nivel de confianza por tipo de dato

| Tipo de dato | Confianza | Acción de la skill |
|---|---|---|
| Fórmulas de vigas | Alta | Calcular directamente |
| Propiedades de materiales (densidad, MOE) | Media-Alta | Usar tabla + advertir variabilidad |
| Carga de herrajes | Media | Usar nominal + margen de seguridad |
| Nesting | Media | Proponer plan, sugerir validación con software |
| Seguridad/estabilidad | Alta (normativa) | Checklist obligatorio + advertencias |

## Notas de uso

- Los datos de fabricantes son referenciales; verificar con el fabricante específico antes de producción.
- Las normativas varían por país/región; la skill usa modo "genérico/conservador" por defecto.
- Para cargas críticas o uso comercial, validar con profesional (ingeniero/carpintero con experiencia).
- Fecha de vigencia de las tablas: 2026. Actualizar periódicamente.
