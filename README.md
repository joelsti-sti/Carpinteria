# Carpinteria

Skill de IA para diseño, cálculo y optimización de muebles y estructuras a medida en madera y metal. Incluye estantes, placares, cajoneras, racks, marcos, puertas corredizas/abatibles, cálculo de neumáticos/gas lifts, selección de herrajes, listas de corte, BOM, nesting y planos.

## Uso

Skill para OpenCode. Copiar la carpeta en ~/.config/opencode/skills/.
